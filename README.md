# Honey-Do-List
The development of a Honey Do List, a shared task management list designed for couples. The system will allow partners to create, assign, and track tasks in real-time, reducing miscommunication and improving household productivity. The features will support comments, tags, and the severity of the tasks, deadlines, reminders, and progress tasks.
